USERSCRIPT MANAGER GUIDE

先装启动器，再装脚本

用户脚本不能单独运行，需要浏览器扩展负责安装、 授权、更新和执行。本站主要推荐 ScriptCat 脚本猫与 Tampermonkey 篡改猴。

安装脚本猫 安装篡改猴
先说结论

来源网站不等于硬性启动器要求

ScriptCat 来源的脚本默认推荐脚本猫； Greasy Fork 来源的脚本默认推荐篡改猴。 但普通 .user.js 脚本通常可以在两者中运行， 最终要看脚本使用的 API 和作者说明。

01

COMPATIBILITY

同一个脚本对启动器有要求吗？

通常都能运行

标准用户脚本

文件以 .user.js 结尾， 只使用常见元数据和 GM_* API。 这类脚本一般可在脚本猫和篡改猴中运行。

需要脚本猫

后台、定时或专属 API 脚本

作者写明“仅脚本猫”，或脚本需要后台常驻、 @cron 定时任务、脚本猫扩展 API 时， 请使用 ScriptCat。

优先篡改猴

作者只测试了 Tampermonkey

如果说明明确要求 Tampermonkey， 或依赖两者实现不同的 API， 应按作者要求使用篡改猴。

不要重复运行： 可以同时安装两个启动器，但不要在两个启动器中同时启用 同一个脚本，否则按钮、请求或自动操作可能执行两次。
02

SCRIPTCAT

ScriptCat 脚本猫安装教程

SC
ScriptCat 来源脚本的推荐启动器

脚本猫

适合普通用户脚本，也支持后台脚本、 定时任务和更丰富的扩展 API。

第一步：从官方扩展商店安装

请根据正在使用的浏览器选择对应按钮。

Chrome 商店 ↗ Edge 商店 ↗ Firefox 商店 ↗
  1. 1

    添加扩展

    在商店页面点击“添加至 Chrome”、 “获取”或“添加到 Firefox”， 阅读权限提示后确认安装。

  2. 2

    开启运行用户脚本的权限

    Chrome 输入 chrome://extensions， Edge 输入 edge://extensions。 找到 ScriptCat，打开“详情”并启用 允许用户脚本。 如果没有这个开关，请在扩展管理页开启 开发者模式。

  3. 3

    重新加载并固定图标

    关闭再开启脚本猫，或重启浏览器。 点击地址栏右侧的扩展按钮，把脚本猫固定到工具栏。

  4. 4

    安装脚本

    回到本站脚本详情页，点击“安装原版脚本”。 脚本猫会打开确认页；检查适用网站、 权限和代码来源后点击安装。

  5. 5

    确认脚本已生效

    打开脚本对应的网站并刷新页面。 点击脚本猫图标，可以查看当前页面正在运行的脚本。

脚本猫官方快速开始 ↗ 官方权限开启说明 ↗ 官方手动安装包 ↗
03

TAMPERMONKEY

Tampermonkey 篡改猴安装教程

TM
Greasy Fork 来源脚本的推荐启动器

篡改猴

主流用户脚本管理器，可安装、更新、 启停和备份 Greasy Fork 等网站提供的用户脚本。

第一步：从官方扩展商店安装

优先使用正式版，不建议从陌生网盘下载扩展。

Chrome 商店 ↗ Edge 商店 ↗ Firefox 商店 ↗
  1. 1

    添加篡改猴

    打开对应扩展商店，确认扩展名称为 Tampermonkey，开发者网站指向 tampermonkey.net，然后添加扩展。

  2. 2

    允许执行用户脚本

    Tampermonkey 5.3+ 在 Chromium 浏览器中需要额外权限。 Chrome/Edge 138+ 可在扩展“详情”中开启 允许用户脚本； 没有该选项时，在扩展管理页开启 开发者模式。

  3. 3

    固定并检查扩展状态

    把篡改猴固定到工具栏。 点击图标后能看到“管理面板”， 说明扩展已经正常启用。

  4. 4

    从本站安装原版脚本

    进入脚本详情页，点击“安装原版脚本”。 在篡改猴确认页检查脚本名称、 匹配网站和申请权限，再点击安装。

  5. 5

    刷新目标网站

    脚本只会在作者声明的网页上运行。 打开目标网站后刷新；篡改猴图标上的数字 通常表示当前页面运行的脚本数量。

篡改猴官方网站 ↗ 官方用户脚本权限说明 ↗ Greasy Fork 安装说明 ↗
04

TROUBLESHOOTING

安装后没有反应怎么办？

点击安装却只下载文件

先确认启动器已启用，并完成“允许用户脚本”设置。 然后重新打开脚本详情页再点击安装， 不要双击运行下载的 JavaScript 文件。

显示已安装但网页没变化

检查脚本是否开启、当前网址是否在适用范围内， 再刷新页面。广告拦截器或同类脚本也可能产生冲突。

启动器图标没有运行数量

可能是当前页面不属于脚本的匹配网站， 也可能没有开启用户脚本权限。 浏览器内部页面通常不允许脚本运行。

脚本猫和篡改猴选哪个？

先按本站详情页的“推荐启动器”选择。 若作者明确要求某个启动器， 作者说明优先于本站默认推荐。

安全提醒

启动器可信，不代表每个脚本都可信

安装前应核对来源、最近更新时间、适用网站和权限。 不安装来源不明、要求关闭浏览器安全功能， 或索要账号密码的脚本。
